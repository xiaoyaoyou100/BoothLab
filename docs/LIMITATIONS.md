# 已知限制与验收范围

UX03 最终结项为 **LIMITED_ACCEPTED**。12 项中 10 项 PASS、1 项 PARTIAL、1 项 NOT RUN。设备适配的正向结论限于 API 17 标准 Phone 测试窗口；约 388 vp 下方案库、输入法和小屏操作通过（UX03-11）。

- **异常与数据恢复（UX03-09：NOT RUN；历史异常恢复限定验收为 PARTIAL）**：设备上的破坏性故障注入、卸载重装及其数据边界未执行。异常回归的既有证据来自隔离的宿主 Mock。正常保存后受控结束进程并恢复三份方案的验证属于 UX03-08，结果为 PASS。
- **物件视觉（UX03-10：PARTIAL）**：十类物件在 100% 下的四个有效方向共 40 个场景完成复核；展品台投影短边小于 18 vp 的低细节档未达到，故为 NOT RUN。座椅在 100% 画布内名称覆盖为 PARTIAL；选中栏的名称完整显示已核对。
- **手势与设备覆盖**：真实并发多点触控时序、大字体、Tablet 和 2in1 均为 NOT RUN。
- **工具栏显示**：编辑器工具栏的模板信息可能出现省略号，记录为 S3，项目负责人接受该观察项。
- **方案库日志**：存在重复的 PlanLibrary `library-message` 警告；验收中未观察到与之关联的运行时故障，该观察项已接受。
- **安装包**：验收使用 debug unsigned HAP。其他设备按目标环境配置签名后部署。

SRS 建议在编辑后做 600 ms 自动保存防抖。当前有效编辑标记 Dirty，保存通过手动操作或返回方案库时触发。详见[需求追踪](REQUIREMENTS_TRACEABILITY.md)。功能和对应实现见[功能说明](FEATURES.md)。
