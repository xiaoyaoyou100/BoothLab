# 课程演示脚本

录屏状态 **NOT RUN**。以下脚本用于后续一段真实操作录屏。准备 API 17 Phone 模拟器和可编辑的演示方案，使用便于辨认的测试名称。进程重启场景以录制时实际观察到的界面、保存状态和物件为准。

| 段落 | 操作与功能 | 拟录画面与解说 | 参考证据 | 注意事项 |
| --- | --- | --- | --- | --- |
| 01 | 启动应用，进入方案库 | 展示应用名称、新建按钮和方案计数。说明这是社团展位编辑器。 | [启动](screenshots/01-library-home.png) | 避免录入个人通知。 |
| 02 | 新建命名方案，比较标准与转角模板 | 切换两种模板，让观众看清开放边差异，再用标准型进入编辑器。 | [标准型](screenshots/02-standard-template.png) · [转角型](screenshots/03-corner-template.png) | 名称为去除首尾空白后 1–30 字符。 |
| 03 | 打开目录并逐个添加接待台、展示桌等至少六件 | 滚动目录，展示分类、卡片预览和计数变化。 | [目录](screenshots/04-object-catalog.png) · INT01-A 添加序列 | 录下点击及每次添加后的画布变化。 |
| 04 | 拖动储物柜，再点选接待台并旋转 | 松手后展示储物柜的新位置。点选接待台进行旋转，让选中栏显示角度和占地变化。 | 储物柜拖动 INT01-A-08b-storage-move · [接待台旋转](screenshots/05-editor-rotation.png) INT01-A-11-rotate-1 | 先选空旷位置，避免旋转被边界拒绝。 |
| 05 | 删除一件，再撤销和重做 | 让计数依次减少、恢复、再减少。 | INT01-A-16-delete / 17-undo-delete / 18-redo-delete | 留出停顿便于看清状态。 |
| 06 | 制造重叠、占用入口及越界，随后修正 | 打开问题列表，移动物件解除提醒，展示越界拒绝后正式位置。 | INT03-B-13-overlap-warning · [入口](screenshots/06-layout-warnings.png) | 入口提示是教学模拟。 |
| 07 | 放大、平移、聚焦，再回全图 | 选择倍率，移动视图，再缩回完整展位。 | [250% 编辑](screenshots/07-viewport.png) · UX03-06 | 使用已验证的单指或按钮路径。 |
| 08 | 显式保存并返回库，展示三份方案 | 等到已保存，回库查看各方案缩略图，再打开原方案。 | 已保存状态 INT01-A-19-saved · [三方案库](screenshots/08-three-plans.png) INT02-00-three-plan-library | 核对名称、模板和物件数量。 |
| 09 | 结束应用进程，重启并逐案重开 | 连续呈现结束、重启、原方案打开与继续编辑。 | INT02-05-stopped / 06-restarted · [续编](screenshots/10-recovery.png) | 只用演示数据。保存、重启及恢复画面均取真实操作。 |
| 10 | 展示最终布局和项目入口 | 以可读的完整画布结束，说明仓库中可以查到源码和运行方法。 | [十类布局](screenshots/09-reopened-layout.png) | 结束画面采用录制过程中实际形成的布局。 |

截图为 API 17 Phone 模拟器已归档原图的逐字节副本。01–08 和 10 来自 UX03-02，09 来自 UX03-03。两类模板的截图展示的是模板选择表单。完整测试范围见[测试指南](TESTING.md)。
